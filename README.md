# صقلية Sicilia — Demo

نسخة عرض (واجهة أمامية) لموقع مطعم **صقلية Sicilia** الإيطالي في إربد. مبنية بـ Vue 3 + Vite.

## التشغيل
```bash
npm install
npm run dev
```

## الرفع على Vercel
ارفع المجلد على GitHub، ثم من Vercel: **Add New → Project → Import**. Vercel يتعرّف على Vite تلقائياً (Build: `npm run build`، Output: `dist`).

## الصور
الـ 19 صورة موجودة داخل المشروع في `public/img/`، وهي صور حقيقية للمطعم من صفحته على Google Maps. الموقع لا يعتمد على أي رابط خارجي للصور.
- `src/photos.js` فيه روابطها الأصلية. إذا أردت تحديثها شغّل `npm run fetch-images`.

## أين أعدّل؟
| الملف | ماذا فيه |
|---|---|
| `src/site.js` | واتساب، الهاتف، الروابط، الإحداثيات، التقييم |
| `src/i18n.js` | النصوص بالعربي والإنجليزي، الأطباق المميزة، القائمة والأسعار |
| `src/styles.css` | الألوان والخطوط (متغيرات أعلى الملف) |
| `src/components/TileBand.vue` | شريط بلاط المايوليكا (SVG) |

## الهوية
الألوان مأخوذة من المطعم نفسه: الأخضر الداكن والرملي من قائمته المطبوعة، والأزرق الكوبالت والأصفر الليموني من صحون وبلاط المايوليكا الصقلية، وشكل القوس من شعاره وديكوره.

## قبل الإطلاق الرسمي
- احذف `<meta name="robots" content="noindex, nofollow">` من `index.html`.
- احذف شريط "نسخة عرض" (`demo-ribbon` في `src/App.vue`).
- تأكد من الأسعار وساعات العمل مع المطعم، واستبدل اسم المطعم النصي بملف الشعار الرسمي.
